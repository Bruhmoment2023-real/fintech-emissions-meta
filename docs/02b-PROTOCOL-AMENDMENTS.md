# Protocol amendments and clarifications (dated)

## 2026-10-17 (before any extraction)
1. Clarification of section 5, degrees of freedom: metafor's partial-correlation formulas use df = N - m - 1 where m counts predictors excluding the intercept. The protocol's "df = N - k, k counting all regressors reported" is the same quantity if k includes the intercept. The analysis code uses m = number of regressors excluding the intercept as extracted ("k_reg" column). No decision about any study depended on this.
2. Section 4: the stage-1 screen has a seventh exclusion code, retracted study or retraction notice (E8). Seven records were coded E8 at stage 1.
3. Section 3: RePEc/IDEAS and EconPapers could not be searched because both require posting the site's search form; the working rules for this task forbid form submissions. The gap is reported rather than filled.
4. Section 3: Semantic Scholar search was rate-limited to partial or empty results on the run date; it is reported as incomplete.
5. Section 5 (selected estimate), added before any extraction: the secondary data set will hold, for each study, the **fully specified estimate** (the column of the same main results table with the most control variables) in addition to the preregistered primary estimate (the first column). Many papers print a covariate-free column first, whose partial correlation is not comparable with a controlled one; reporting both avoids letting that choice drive the result. Both are analysed; the primary analysis remains the preregistered first-column rule.
6. Spatial models (SAR, SDM, SEM): the coefficient on the fintech variable in the model's main (non-spatial-lag) term is used; direct and total effects are not mixed. Models where the fintech variable enters only through interaction terms are not extractable.
7. Added during extraction, before any estimate was analysed: when a table prints a coefficient whose significance stars are inconsistent with the printed standard error or t statistic (for example -0.0180*** with SE 0.03), the estimate is **kept with the printed SE or t and flagged** `INCONSISTENT` rather than dropped; the meta-analysis reports a sensitivity analysis that excludes flagged rows. Three records I had excluded at first for this reason (10.1371/journal.pone.0302826, 10.3389/fenvs.2022.1045878) were re-entered under this rule; 10.1371/journal.pone.0307328 stays excluded because its bracketed values are standard deviations, not SEs, and the table layout cannot be matched to a model.
8. Fallback for the preregistered first column: if the first column's SE rounds to zero (so t is undefined), the first usable column of the same table is used and flagged `primary_fallback`.
9. Standard errors printed with a negative sign are taken in absolute value (typography).
10. N inferred from panel dimensions (units x years) when a table omits the observation count is flagged `N_inferred` in the notes; a sensitivity analysis excludes those studies.
