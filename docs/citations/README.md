# Citation library (pack 14)
- `references.bib` (64 entries) and `references.ris` (64 entries), built from Crossref's BibTeX and RIS transforms by `code/build_citations14.py`; every BibTeX entry carries a `note` saying why it is in the pack. 64 unique DOIs requested.
- Scope: the 55 included studies, seven method sources (metafor, PRISMA 2020, PET-PEESE, Egger, CR2 cluster-robust variance, MAER-Net guidelines, power of bias) and the two closest prior syntheses (metadata only; both are closed access).
- DOIs for which Crossref returned no BibTeX: [].
- Import into Zotero: File > Import and choose `references.ris` (or `references.bib`). Check titles after import; Crossref sometimes keeps HTML entities.
